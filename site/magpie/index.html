Magpie

A personal backup tool for the Whitesberg home network.

Magpie runs on its owner's own computers. Each night it packs chosen folders into one encrypted archive and copies it to a home file server and to the owner's own Google Drive. It keeps the newest archives and deletes older ones.

How Magpie uses Google Drive

  • It uploads its own backup archives to a folder in the owner's Google Drive.
  • It lists and deletes only the archives it uploaded.
  • It doesn't read, change or share any other file in Google Drive.

Who can use it

Magpie is a private tool with a single user, its owner. It isn't offered to the public and has no sign-up.
